# Планер

Личный планер: неделя по горизонтали, день, месяц, входящие, подзадачи, повторы,
вкладка Instagram для контент-стратегии и голосовой ассистент.

## Что здесь лежит

- `prototype/index.html` — рабочий прототип, который живёт как артефакт Claude:
  https://claude.ai/artifact/MWwzuHrStmPrgL3t8fDEoB
  Хранилище, приветствие по имени и ассистент работают только внутри Claude.

## Дальше

Отдельное веб-приложение (PWA) со своей регистрацией: открывается в браузере,
ставится на экран «Домой» на iPhone, присылает уведомления.
